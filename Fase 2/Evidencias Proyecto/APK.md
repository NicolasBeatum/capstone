# APK de DuocMind

La APK se distribuye desde el apartado [Releases del repositorio](https://github.com/NicolasBeatum/capstone/releases), como archivo adjunto de cada versión, junto con su checksum SHA-256.

La primera release, **v0.1.0**, se publicará automáticamente cuando se fusione el PR de `dev` hacia `main` con el [workflow de release](../../.github/workflows/android-main-release.yml). Hasta que ocurra ese merge, esta versión todavía no está publicada en Releases.
